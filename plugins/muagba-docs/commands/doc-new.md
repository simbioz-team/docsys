Создай новый документ. Аргументы: `тип [название]`.

## Шаг 1. Конфиг и тип

Прочитай `.claude/doc-config.json`. Нет файла — скажи запустить `/doc-init`
и остановись.

Тип должен совпасть с одним из `types[].name`. Не совпал или не указан — выведи
список допустимых и остановись. Название не указано — спроси.

## Шаг 2. Путь

Возьми `path` типа. Подставь:

- `{slug}` — транслитерированное название: кириллица → латиница, пробелы → `-`,
  строчные, только `a-z 0-9 -`
- `{NNN}` — следующий свободный номер: просканируй каталог, возьми max + 1,
  дополни нулями до трёх знаков

Файл уже есть — скажи об этом и предложи `/doc-update`. Не перезаписывай.

## Шаг 3. Tier

Поле `tier` отделяет правила уровня всего проекта от привязанных к одной фиче.

- `adr`, `overview`, `design`, `requirement`, `reference` → **спроси**:
  - `foundation` — правило или контракт уровня проекта, применимо к любой
    существующей и будущей фиче, меняется редко
  - `feature` — привязано к одной фиче или функциональной зоне
  - `feature-derived` — описывает то, что уже реализовано, следует из кода
- остальные типы → поле неприменимо, удали строку из frontmatter

## Шаг 4. Frontmatter

Заполни из шаблона `${CLAUDE_PLUGIN_ROOT}/templates/<template>`:

```yaml
title: <название>
scope: product          # meta — если документ про процесс, а не про продукт
type: <тип>
tier: <из шага 3>
status: draft           # active ставится после проверки, не при создании
updated: <ГГГГ-ММ-ДД>
tags: [<3-6 тегов>]
summary: <1-3 предложения: о чём документ и какое решение фиксирует>
```

`summary` — не пересказ оглавления. По нему агент решает, открывать документ или
нет, поэтому в нём должно быть содержание, а не тема.

Плейсхолдеры тела оставь как есть — их заполняет автор.

## Шаг 5. Реестры

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/rebuild_registries.py"
```

Руками реестры не правь: скрипт перестроит и затрёт правку.

## Итог

Путь созданного файла, тип, tier, статус. Напомни: `status: draft` меняется на
`active` только после того, как документ прочитан и проверен.
