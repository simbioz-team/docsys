Проверь документацию.

## Шаг 1. Прогон

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/check_docs.py"
```

Одна проверка вместо всех: `--only frontmatter|registries|status|links|freshness`.
Сделать свежесть гейтом: `--strict`.

## Шаг 2. Разбор находок

| Проверка | Что означает находка | Что делать |
|---|---|---|
| `frontmatter` | значение поля вне словаря, битая дата, документ не там, где предписано типу, остался плейсхолдер шаблона | привести значение к словарю из `.claude/doc-config.json`, перенести файл или заполнить шаблон |
| `registries` | реестры разошлись с документами | `rebuild_registries.py` |
| `status` | статус в теле (`## Status` или строка `- **status:**`) ≠ frontmatter, либо active ссылается на draft или мёртвое, в том числе между `docs/` и `specs/` | строку статуса в теле убрать — статус живёт во frontmatter; ссылку — на активный источник или снять |
| `links` | ссылка не открывается | поправить путь, снять ссылку или закрыть hatch'ем с причиной |
| `freshness` | документ отстал от кода, который описывает | прочитать и обновить либо понизить статус |

Проверки обходят `docs_dir` и шаблоны `extra_roots`; рабочие материалы рядом
со спекой (`plan.md`, `tasks.md`) документами не считаются. Предупреждение
`status_copy` гейт не роняет: строку статуса в теле, совпавшую с frontmatter,
стоит убрать.

## Шаг 3. Правки

Чини по одной находке, не пакетом: у каждой своя причина, и правка вслепую
плодит новые.

Для `links` есть отвод — `<!-- noqa: doc-links <причина> -->`. Причина
обязательна. Отводом закрывают ссылку, которую чинить нечем, а не ту, которую
лень поправить.

Для `status` — `<!-- noqa: doc-status-bypass <причина> -->`, для `frontmatter` —
`<!-- noqa: doc-frontmatter <причина> -->`. То же правило.

## Шаг 4. Перепрогон

Повтори шаг 1. Не докладывай о готовности, пока красное.
